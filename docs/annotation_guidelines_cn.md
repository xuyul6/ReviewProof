# 金标标注规范（gold-v1）

本规范供子 agent 预标和人工审核共用。每条标注都记录规范版本 `gold-v1`。规范改了就升版本号，旧标注不混用。

## 1. 判断依据

- **只看这件商品的评论。** 不用常识，不看社区回答，不看其他商品。
- 评论是西班牙语等其他语言的，同样算数。
- 候选池是系统从这件商品的评论里挑出的一批评论块，按编号排列，排列顺序没有含义。候选池里没有答案、但怀疑评论里有时，先用搜索找（见第 5 节），再下"不能回答"的结论。

## 2. 可答性（三选一）

**answered（能回答）**
- 评论里有直接回答问题核心的内容。一位买家的明确陈述就够，写理由时按"有买家说……"转述，不当成事实。
- 买家意见不一，也算 answered，结论记为 mixed。
- 例：问"声音大吗？"，有评论说"晚上太吵，睡不着"。

**partial（部分能回答）**
- 问题有几个部分，评论只回答了其中一部分。例：问"防水吗？能放洗碗机吗？"，评论只说了防水。
- 或者只有相近情形的信息。例：问"2012 款 F-150 能装吗？"，评论说 2013 款装上了。

**unanswerable（不能回答）**
- 评论里没有提到。
- 问题本身超出评论的范围（保修条款、官方尺寸、去哪里买、和别的商品比较）时，要看评论里有没有相关的亲身经历：
  - 有，就按内容判 partial 或 answered。例：问"保修几年？"，评论说"坏了以后厂家免费换了一个"，判 partial。
  - 没有，才判 unanswerable。

## 3. 证据等级（每个候选块都要给）

| 等级 | 含义 | 例（问题：声音大吗？） |
|---|---|---|
| 2 | 单独读这一块，就能支撑回答或回答的一部分 | "风扇很吵，开到最大像吹风机。" |
| 1 | 相关，但单独读不足以支撑回答 | "我把它放在卧室里用。" |
| 0 | 无关 | "包装很结实，发货快。" |

- answered 和 partial 至少要有一个等级 2 的块。
- unanswerable 不能有等级 2 的块，不要为了凑数编造证据。

## 4. 是非题结论

只有题型为 `yesno` 的题需要填，其他题型留空（null）。

| 结论 | 什么时候用 |
|---|---|
| yes | 评论支持"是" |
| no | 评论支持"否" |
| mixed | 买家说法不一 |
| unknown | 可答性为 unanswerable 时必须用它，其他情况不能用 |

## 5. 找证据

- 先读完候选池的每一块，再判断。
- 候选池里找不到答案时，用搜索在这件商品的全部评论里查关键词（换几种说法，比如型号、尺寸单位、同义词）。搜到的块也给等级，一起写进 `grades`。
- 搜过几次仍然找不到，才判 unanswerable，并在理由里写明搜过什么。

## 6. 理由

用一两句话说明依据哪几块（写块编号），以及为什么是这个可答性。例："A-r00012-c00 有买家说装在 2013 款上合适，问的是 2012 款，属于相近情形，判 partial。"

## 7. 输出格式（子 agent 预标）

每题一行 JSON：

```json
{"qid": "...", "answerability": "answered|partial|unanswerable", "verdict": "yes|no|mixed|unknown 或 null", "grades": {"<chunk_id>": 0, "<chunk_id>": 2}, "rationale": "...", "annotator": "agent:<model>"}
```

候选池里的每个块都要出现在 `grades` 里；搜索找到的池外块也可以加进去。
